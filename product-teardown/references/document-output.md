# Word 与 HTML 双文件交付

默认同时输出 `<产品名>-产品拆解报告.docx` 和 `<产品名>-产品拆解报告.html`，存放于同一输出目录。Word 是可编辑的真实 OOXML 文档；不要将 HTML、纯文本或 Markdown 改扩展名作为 .docx，也不要只提供 PDF。用户明确指定单一格式时遵循。

## 从同一内容生成

先确定完整分析与证据清单，再排成两种形式。至少保留相同的产品与体验范围、研究日期、端/账号/版本条件、定位、竞品比较、结构流程、核心需求、问题建议、来源和待确认项。表述可以适配媒介，结论、数值、确定性、编号和限制必须一致。

- HTML：可折叠需求和证据，提供页内目录，图形可交互；关键缺口不只藏在折叠区。
- Word：需求与证据全部展开，不能因 HTML 默认收起而漏掉内容。使用原生标题、段落、列表和表格；不能把整页网页截成图替代可编辑正文。
- 长表可拆成多张或转需求卡；换布局不能删掉比较条件或重要字段。
- 截图在两份中保留同一来源、时间和说明；HTML 用 data URL 或随附资源，Word 直接嵌入文件，不依赖研究机器路径。
- HTML 的 SVG/交互图在 Word 中使用实际渲染的清晰 PNG 或等价静态图。必要时另附文字说明分支、条件和验证状态，不能直接塞入未渲染 Mermaid/SVG 源码；交互才能看到的关键事实要有静态表达。

## 两种格式保持相同主次

正文遵循 report-template.md 的主场景叙事，核心流程与决定性机制深拆；支撑材料简述，完整覆盖和字段/权限资料后置为附录。HTML 的附录在 Word 中展开，但仍留在正文之后，不能因展开就把它们全部提升为一级主文。关键未知和限制在两份主文中同样可见。

## Word 创建与排版

使用当前环境实际可用的文档工具。若有 documents 技能，遵循其创建与渲染检查流程；没有该技能时，本规范也应足够执行：用 python-docx 或 OOXML 等可用工具生成真实文档。运行环境由可用的依赖加载工具确定，不假定其他机器存在本机绝对路径。缺依赖时按环境授权安装或使用现有工具，不能因此默默只交付 HTML。

建议版式（用户有模板则优先）：

- A4、适当页边距、中文字体及西文字体明确，正文约 10.5—11 pt、适度行距。
- 主标题使用 Title，一级/二级标题使用 Heading 样式；清楚说明主题、目的、范围和主要结论。长文便于导航，不添加没有内容的装饰封面。
- 需求卡使用二/三级标题与段落；状态写出“确定项/不确定项/需二次确认项”，不能只靠颜色区分。
- 表头可重复，列宽合计不超过版心；避免窄列塞长文。标题与后文保持同页，长表允许合理跨页，行不截断；过高行先拆解内容。
- 图像保持比例，宽度不超过版心；文字在正常缩放下可读，图题与图片相邻。流程图箭头与判断条件清楚，不用模糊长截图替代图解。
- 保留可访问的来源链接与证据编号。长文加页码；来源与待确认项是正文的一部分，不能在 Word 中省略。

不要假定 Word 能原样渲染网页 CSS。允许根据阅读和打印重新排版，但不能弱化证据边界。

## 检查与交付

1. 用可用的 Word/LibreOffice 渲染器或文档预览工具将 `.docx` 渲染为页面图或 PDF 预览，逐页检查截字、溢出、空白页、孤立标题、表格和图像。存在 documents 技能时优先用其 `render_docx.py` 流程。预览是 QA 中间产物，默认仍交付 DOCX 与 HTML。
2. 按 html-output.md 在浏览器检查 HTML 的桌面、窄屏、目录、折叠、图表与资源。
3. 使用标准库脚本做双文件基础检查：

```sh
python3 <skill-dir>/scripts/check_deliverables.py <报告.docx> <报告.html>
```

它检查 DOCX 包和正文、HTML 文档与本地资源，并比较两份中 F/E/I/Q 编号集合。编号差异会报错，帮助发现折叠内容漏进 Word 或输出版本不一致；需回到内容核实，不能简单删除编号来通过检查。没有编号的短报告也能检查。该脚本不验证分析真伪、逐项数值、版式或图形含义。
4. 手工对照两份的关键结论、范围条件、竞品数据、图形分支、需求规则、来源、待确认项，修复不一致。不能只比较标题或文件大小。
5. 无渲染能力时做包结构、正文、资源与两份内容检查，并在最终说明未完成 Word 视觉检查；不能声称版式已验证。无法生成 DOCX 时继续解决实际依赖问题，确有阻碍才清楚说明缺失，不将 HTML 或 PDF 冒充文档。

最终提供两个分别标明格式的文件链接和少量结论。更新 Skill 到 GitHub 仅提交方法、模板与工具，不自动公开拆解报告、项目截图或账号数据。
